# Clix Documentation

Clix is a Dart CLI toolkit for building powerful and interactive
command-line applications.

## Documentation

### Commands

Build structured CLI applications with commands, arguments, options,
flags, subcommands, aliases, help, usage, and suggestions.

[Explore Commands →](commands/README.md)

### Prompts

Collect interactive user input with text, passwords, confirmations,
selection, numbers, decimals, search, and validation.

[Explore Prompts →](prompts/README.md)

### Logger

Create clear and expressive terminal output using messages, colors,
icons, marks, points, hints, and tables.

[Explore Logger →](logger/README.md)

### Progress

Display progress bars, spinners, and multiple task states.

[Explore Progress →](progress/README.md)

### Styling

Customize colors, themes, styles, spacing, padding, hints,
and indentation.

[Explore Styling →](styling/README.md)
